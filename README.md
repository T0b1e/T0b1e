## Currently (a random IT guy, full-time)

Projects I've shipped — feel free to be my beta tester and roast them.

**container-tracking** — Built from a client requirement: a SaaS catalog system for a firm that needed to track container status (gen-set or not).

**pwi** — Where I currently work full-time. Things I've done here:
- Built a custom ML model for counting items on a conveyor belt (currently porting this to a Jetson Orin board)
- Built a Warehouse Management System that doubles as ERP/back-office, using Next.js and Elysia
- Turned that WMS into a PWA
- Built a master dashboard showing live stats for the office
- Pushed the company toward going paperless and moving more onto the cloud

I also build websites for fun:

**horpuck** — Built for my uncle, who needed an apartment rental management system. In the end he told me it barely helped — turns out the paperwork was never the real problem, people were.
🔗 [horpuck.pages.dev](https://horpuck.pages.dev/)

**fakwainaijai** — As a university student, I kept running into this: using public print-shop PCs required logging into Facebook, LINE, Gmail, or Google Drive to grab your files. If you've been a student, you know the drill. What bugged me was that the previous user often forgot to log out — which got me thinking about security.
🔗 [fakwainaijai.narongkorn.com](https://fakwainaijai.narongkorn.com/)

**taxi-fare app** — My idea: can we clone the logic behind a Thai taxi meter? Turns out yes — fare is based on distance and time (with extra ticking during traffic jams). This web app/PWA lets you check whether your fare is running unusually high compared to what it should be.
🔗 [taxi.narongkorn.com](https://taxi.narongkorn.com/)

**color-meter** — I needed the color code of my wall paint but couldn't just snap a photo — lighting, shadows, and the camera itself all throw the color off. So I built this to work around that.
🔗 [color-meter.narongkorn.com](https://color-meter.narongkorn.com/)

**bill-share** — An idea from 2023 with a friend: an app to split costs for group activities like dinners or trips. Planning to add bill/receipt OCR next.
🔗 [bill.narongkorn.com](https://bill.narongkorn.com/)

**fak-tuan** — A short-notice reminder tool. How do you keep track of something happening in a few hours, or even 15 minutes? Most people rely on their phone's reminder app or a notes app — and then forget anyway. So I built this as a LINE chatbot instead.
🔗 [fak-tuan.narongkorn.com](https://fak-tuan.narongkorn.com/)

**red-line-api** — Built for my personal ledger project. The real problem with most ledger/payment apps today is human error — we're too lazy to log cash transactions, since online payments already track themselves.

**withub** — Just GitHub, but for Word docs. If you know, you know.

**grade prediction** — Built for a friend, so they could calculate their GPA more easily instead of manually looking up values and typing them into another site.

**kmap 3D** — A vibe project to learn how three.js works.

**chit-chat** — A P2P platform to chat, send text, or share files with classmates — no need to log into Facebook, Messenger, etc.

**kinyayang** — An app to remind my dad not to forget to take his pills, and to keep a personal medicine log. Next feature: hooking it up to a LINE chatbot.

**reality-font-size** — An AR tool comparing text size to real-world scale — thinking of using it for poster design.
